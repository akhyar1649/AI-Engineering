# Rubric Final Project

| Kriteria | Bobot |
|---|---:|
| Problem framing dan business fit | 15% |
| Architecture/data/integration design | 20% |
| Technical implementation | 20% |
| Reliability, security, governance | 15% |
| Deployment, operations, cost | 15% |
| Development strategy dan delivery plan | 10% |
| Report/presentation/stakeholder communication | 5% |

## Minimum pass criteria

- ada solusi runnable dengan data sintetis;
- ada evidence test dan acceptance;
- ada deployment/demo yang dapat direproduksi;
- ada rollback/recovery dan risk control;
- ada keputusan trade-off yang dapat dipertanggungjawabkan.

## Presentation

Presentasi 15–20 menit: problem, outcome, architecture, demo, evidence, trade-off, risk, cost, roadmap, dan keputusan yang diminta dari stakeholder.
