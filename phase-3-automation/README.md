# Fase 3 — Automation

## Output fase

Pada akhir fase ini Anda mampu menerjemahkan proses bisnis menjadi workflow n8n yang reliable, menghubungkan database/API/AI/MCP, memilih deployment strategy, dan menyusun governance automation.

## Urutan part

1. Principles of Automation
2. n8n Fundamentals
3. n8n Data Handling & Logic
4. MCP (Model Context Protocol)
5. n8n Reliability
6. Scheduling & Triggering
7. Integrated System
8. Deployment Strategy & Cost Analysis
9. Self-Hosted Infrastructure Setup
10. Monitoring & Observability for Automation
11. AI on Automation
12. Troubleshooting Automation and Governance
13. Translating Business Process to Automation Flow
14. Automation Design & Solution Fit
15. Integration Readiness & System Compatibility

## Narasi fase

Sari ingin mengurangi pekerjaan manual: menerima event shipment, memperbarui status, mengirim notifikasi, membuat tiket jika terjadi anomali, dan meminta bantuan AI hanya ketika input membutuhkan interpretasi. Peserta merancang workflow yang memiliki idempotency, retry, audit, approval, dan cost boundary.

## Kesatuan pembelajaran

Part 1–5 membangun vocabulary workflow, data shape, MCP capability, dan reliability. Part 6–10 menghubungkan trigger, system, deployment, self-hosting, dan observability. Part 11–15 menempatkan AI secara bounded lalu menerjemahkan proses bisnis menjadi desain yang siap diintegrasikan. Capstone 3 harus dapat ditelusuri dari process canvas hingga SLO dan recovery runbook.

Gunakan [Assessment Handbook](../docs/00-assessment-handbook.md) untuk alur pengerjaan, tools/versi, workflow evidence, replay, deployment, dan self-check. Capstone 3 memiliki milestone dan Definition of done sendiri di [case brief](capstone/case-brief.md).
