# Rubric Capstone 3

| Kriteria | Bobot |
|---|---:|
| Workflow technical correctness | 25% |
| Reliability/idempotency/replay | 20% |
| Integration/deployment | 20% |
| AI/MCP safety and governance | 15% |
| Observability/cost | 10% |
| Dokumentasi/presentasi | 10% |

## Evidence minimum

- demo normal dan failure path;
- proof duplicate tidak menggandakan side effect;
- DLQ/replay evidence;
- readiness scorecard;
- live/self-hosted deployment dan restore/runbook;
- cost model dan SLO.
