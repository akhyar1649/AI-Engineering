# Rubric Capstone 1

| Kriteria | Bobot | Evidence |
|---|---:|---|
| Technical correctness | 30% | pipeline, schema, cleaning, quality, tests |
| Data quality dan governance | 20% | rule, severity, owner, quarantine, lineage |
| Reliability dan operasi | 15% | idempotence, retry policy, SLO, runbook |
| Deployment | 15% | live URL/demo, reproducible setup, health check |
| Code quality | 10% | struktur, typing, readability, config |
| Dokumentasi/presentasi | 10% | trade-off, cost, hasil, demo |

## Skala

- **Excellent:** end-to-end berjalan, evidence lengkap, trade-off terukur, dan failure path diuji.
- **Good:** mayoritas requirement terpenuhi, ada gap kecil pada operasi atau dokumentasi.
- **Needs revision:** pipeline hanya bekerja pada happy path atau tidak dapat direproduksi.
- **Incomplete:** deliverable inti, quality evidence, atau deployment tidak tersedia.
