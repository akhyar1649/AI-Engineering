# Solution Explanation — AI and LLM Principle

Solusi memilih retrieval untuk knowledge SOP yang sering berubah, model cepat untuk routing, dan model lebih kuat hanya untuk kasus ambigu. Contract mencatat model snapshot, prompt version, token usage, evidence status, dan escalation.

Kesalahan umum adalah menganggap temperature sebagai tombol factuality, memakai fine-tuning untuk memperbarui SOP, dan menilai model hanya dari satu jawaban demo.
