# Rubric Capstone 2

| Kriteria | Bobot |
|---|---:|
| Technical correctness dan integration | 25% |
| Retrieval/evaluation quality | 20% |
| Reliability, risk, dan governance | 20% |
| Deployment dan observability | 15% |
| Code quality dan testing | 10% |
| Dokumentasi/presentasi/trade-off | 10% |

## Evidence minimum

- demo happy path dan failure path;
- evaluation report dengan baseline;
- sanitized trace sample;
- risk register dengan owner/control;
- live URL atau local deployment reproducible.
